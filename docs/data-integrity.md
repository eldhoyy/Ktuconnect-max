# Academic data integrity

## Timetables

The ported timetable helpers deliberately distinguish discovery from approval. A third-party index page is not proof of official status. A candidate can only be promoted when its source/document evidence matches the supported KTU B.Tech scope and a human reviewer has approved it. Student-entered dates are personal planning data and must carry an **Unverified — entered by you** label.

## Learning resources

Only resources with `verification_status = approved` may be shown in public Learn experiences. Preserve source URLs and verification timestamps. Do not mirror copyrighted notes or papers without permission; link to the legitimate source instead.

## Repeated topics

`src/data/important-topics.json` carries evidence summaries and paper counts from the source project. A high-priority label is a description of observed paper evidence, not a guarantee or prediction of future exam questions. Syllabus-only topic guides must not be presented as paper-frequency analysis.
